# src/components/

Componentes React reutilizables, organizados en subcarpetas por función.

## Subcarpetas

| Carpeta | Contenido |
|---------|-----------|
| `layout/` | Estructura base de la app: sidebar, topbar, navegación inferior |
| `ui/` | Componentes visuales reutilizables: mapa corporal, gráfica de ejercicio, toggle de tema |

Cada subcarpeta tiene su propio README con detalle de cada componente.
